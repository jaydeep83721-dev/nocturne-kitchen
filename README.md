# Nocturne Kitchen

Responsive restaurant website with an interactive menu, individual dish visuals, a Dish of the Night showcase, and a full-screen reservation experience.

## Deploy to Vercel

1. Extract this ZIP.
2. Upload the extracted folder to a GitHub repository.
3. In Vercel, select **Add New → Project**.
4. Import the repository.
5. Leave **Framework Preset** as **Other**.
6. Leave the build command empty.
7. Set the output directory to `.`.
8. Select **Deploy**.

You can also install the Vercel CLI and run `vercel` from this folder.

## Edit the website

- `index.html` — content and page structure
- `styles.css` — original visual design
- `reservation.css` — full-screen reservation design
- `selection.css` — clickable dish showcase
- `script.js` — menu, reservation and ambience interactions
- `menu-visual.js` — individual dish image switching
- `reservation.js` — seating-area selection
- `assets/` — food images

After editing files in a connected GitHub repository, push the changes. Vercel will redeploy automatically.
